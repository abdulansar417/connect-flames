# Connect Flames

A student community and peer-support platform designed to help university students connect, share experiences, ask questions, and navigate campus life.

## Overview

Connect Flames aims to make the university experience easier for students, particularly those adjusting to a new campus, academic environment, or community. It provides a platform where students can seek guidance, exchange information, and connect with others.

## Features

- Student community and peer support
- Question-and-answer platform
- Student connection and knowledge sharing
- Support for navigating university life
